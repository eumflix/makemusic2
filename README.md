# 나도 작곡가 (eumflix composer)

음플릭스 · 대제중학교 이현도. 코드 규칙으로 배우는 작곡 웹앱입니다. 서버 없이 정적 파일만으로 동작해요.

## 파일

- `index.html` : 나도 작곡가 (레벨 0~5, 학생용)
- `eval.html` : 평가용 (레벨 2~4, 점수·결과를 학생에게 보여 주지 않고 「제출 코드」만 만들어요)
- `collector.html` : **교사용 평가 분석툴** (학생 제출 코드를 채점해서 학급·학생 보고서를 만들어요)
- `.nojekyll`, `README.md`

GitHub Pages에는 이 폴더의 파일을 모두 올리면 돼요. 같은 저장소 안에서 `collector.html`이 `eval.html`, `index.html`과 나란히 열려요. 새 저장소가 따로 필요 없어요.

## 평가 진행 방법 (선생님)

1. `eval.html`을 열어 레벨·마디 수·비화성음 횟수·도약 한도를 정하고 학생에게 주소를 알려 줘요.
2. **코드 받기(기본)**: 학생이 평가를 마치면 「📋 코드 복사」 버튼으로 제출 코드를 복사해요. 코드는 `EV2|…`로 시작하는 읽을 수 없는 글자이고, 선생님만 읽을 수 있어요. 학생은 이 코드를 선생님이 정한 곳(구글폼·클래스룸·카톡 등)에 붙여 넣어요.
3. **구글폼 연결(편의)**: `eval.html` 첫 화면 맨 아래 「선생님 · 구글폼으로 결과 받기」에 구글폼 주소를 붙여 넣고 「학생용 주소 만들기」를 눌러요. 이 학생용 주소로 들어온 학생은 코드 복사 버튼 옆에 「📝 선생님 폼 열기」가 함께 떠요. (고급: 폼의 「양식 미리 작성」에서 질문에 `제출코드`라고 적고 만든 주소를 붙여 넣으면 코드가 자동으로 채워져요.) `eval.html?setup=1`로 열면 진행 중인 평가가 있어도 이 화면이 보여요.
4. 응답 시트의 코드 열을 복사해서 `collector.html`에 붙여 넣으면 채점·보고서가 나와요. 채점 기준(레벨·비화성음 횟수·도약·점수 비중)은 분석툴에서 바꿀 수 있고, 모든 계산은 브라우저 안에서만 이뤄져요.

## 제출 코드 형식 (EV2)

`EV2|이름|반|레벨|마디|2번째음횟수|4번째음횟수|도약|이탈횟수|이탈초|제출시각|코드진행|음표|검산`
음표 한 개 = 알파벳 2글자(음높이 A~X = 다장조 C3~E6, 길이 A=8분 · B=4분 · C=점4분 · D=2분 · E=온음표), 마디는 `-`로 구분.
